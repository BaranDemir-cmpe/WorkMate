# WorkMate

WorkMate is an Android application developed as a graduation project.

The project includes Firebase integration, PDF processing, and AI-powered CV analysis using the Google Gemini API.

## Technologies

- Java
- Android Studio
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
- Google Gemini API
- PDFBox
- Glide

## Features

- User authentication
- Firebase database and storage integration
- PDF CV upload
- CV text extraction
- AI-powered CV analysis
